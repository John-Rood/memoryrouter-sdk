## Repository issues

Use this repository's issue tracker only for reproducible problems with its README, release assets, or legacy patch helpers. Include your operating system, architecture, relevant command output, and the release or file version involved.

Never post live Memory Keys, provider credentials, OAuth tokens, customer data, or private memory content in an issue.

## Security reports

Suspected vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md), not through a public issue.
